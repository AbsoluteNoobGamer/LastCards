Release notes · Version 1.0.6

Version 1.0.6

Gameplay

  • Queens no longer bypass mid-turn play restrictions
  • You can’t win by leaving a Queen uncovered on the discard
  • Combo chains reset correctly when stacked Eights wrap the turn back to you

New

  • Arena Neon table theme with soft-gold combo feedback
  • Unlockable in-game avatars (Locker + online)
  • Live text chat in lobby and at the table, with report/block
  • Animated how-to-play tutorial for special cards
  • Rematch across offline, online, and Bust
  • Casual tournament vote, rejoin, and 3-player knockout
  • Remove Ads one-time purchase
  • Tournament Online leaderboard

Improvements

  • Settings, back, chat, and reactions sit above the timer so hand cards are easier to tap
  • Tablet / large-screen layout: piles stay tappable; overlays no longer cover the board
  • If someone disconnects mid-match, AI takes over quietly instead of ending the game
  • Matchmaking timeouts retry in place; longer real-player search window
  • Guest rename nudge; name prompt when Apple/email sign-in has no display name
  • Privacy: analytics consent, opt-out, and account deletion flows

Fixes

  • Draw / discard piles no longer become untappable on large screens
  • Live chat composer accepts input at the table
  • Casual knockout vote appears after matchmaking
  • Online rematch no longer bounces to the start screen when no tables are open
  • False Last Cards bluff / declare edge cases
  • Launch splash matches the in-app casino screen (no jarring flash)
  • Head-to-head stats no longer double-count
